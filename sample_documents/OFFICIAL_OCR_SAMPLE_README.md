# Local government document samples

Select `official_delhi_fire_safety_certificate.pdf` in the portal's local file
picker for a public Delhi Fire Service certificate. For pixel OCR tests select
`official_certificate_image_only.pdf` or `official_certificate_page_1.png`.

These are unchanged copies of the prepared OCR test artifacts. The certificate
belongs to Hari Vidhya Bhawan School; it is not a renewed certificate for Cedar
Institute and does not carry the script's placeholder DFS/HQ/2026/FSC/8842.
Use it as demonstration/test evidence and enter its actual details.

Official source: https://dfs.delhi.gov.in/node/15964
Application ID: 52026021801098. Issue date: 06 March 2026.
No separate expiry date is printed. Provenance and expected extraction fields
remain in `output/pdf/ocr_manual_test/`.
